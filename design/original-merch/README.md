# Original Hasnas merch

This folder collects the Hasnas Coffee apparel concepts developed for the storefront.

- `concepts/` contains the saved product mockups and front/back presentation images.
- `svg/` contains the corresponding transparent, path-based print artwork separated by placement.

The leading number connects an SVG to its concept mockup. Some concepts intentionally preserve
earlier iterations so the approved colors and alternate treatments remain available.

The SVG artwork was traced from concept imagery. Before production, inspect small lettering and
fine linework at final print size and have the printer clean or reset type where necessary.
